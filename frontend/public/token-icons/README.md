# Local token SVG assets

The following token marks are stored locally: APT, ARB, OP, INJ, TIA, FIL.

Source project: https://github.com/0xa3k5/web3icons
Source files: packages/core/src/svgs/tokens/background/{APT,ARB,OP,INJ,TIA,FIL}.svg
Source package: @web3icons/core (MIT; see the upstream package README and package metadata).

These are token brand marks. Their names and marks remain associated with their respective projects and trademark owners. BTCBOX uses them only to identify the corresponding assets; no endorsement or affiliation is implied.

The SVGs are stored locally so the UI does not need a third-party image request at runtime.
