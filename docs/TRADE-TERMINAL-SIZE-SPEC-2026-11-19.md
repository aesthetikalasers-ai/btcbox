## 5. 页面级布局

### 5.1 桌面
- 三栏 Grid：`280px minmax(400px,1fr) 320px`，gap 12。
- 顶部交易信息栏高 64（交易对、最新价、24h 高低量）。
- 主交易区高 520–680；下方订单管理区 240–320，全宽，可展开/收起/拖高。
- Tab 顺序：当前委托 → 历史委托 → 成交历史 → 当前持仓 → 资产与盈亏。
- ≥1600 五栏：+币种列表 220 +最新成交 240。
- 1280–1439：盘口与成交合并为 Tab。
- 1024–1279：币种列表收进顶部交易对选择入口。

### 5.2 手机（独立设计，基准 390，适配 320–430）
- 页面左右边距 12。
- 顺序（不得变）：① 顶部交易对导航(48) → ② 当前价格+24h(约100，主价24) → ③ 买入/卖出下单 → ④ 订单簿 → ⑤ 当前委托及持仓(Tab40+纵向卡片) → ⑥ 底部固定导航。
- 底部导航：五项 Home/Markets/Trade/Assets/Me，高 56 + safe-area，图标 22×22、标签 10、图文间距 4。
- 输入框字体 ≥16；键盘弹出提交按钮可见。
